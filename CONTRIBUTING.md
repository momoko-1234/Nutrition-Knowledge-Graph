# Contributing

Thank you for helping improve Nutrition Knowledge Graph.

## Ways to contribute

- Report an incorrect or misleading relationship
- Propose a food, nutrient, or benefit node
- Add a reliable source to an existing relationship
- Improve search, filters, accessibility, mobile behavior, or translations

## Data contribution requirements

When proposing nutrition or health information, include:

1. The exact node or relationship being changed.
2. A plain-language reason for the change.
3. A stable source such as a DOI, PubMed page, government health agency, or recognized scientific institution.
4. Whether the source supports association, biological mechanism, or clinical outcome.

Health claims without a verifiable source should not be merged. Contributors must avoid diagnosis, treatment promises, and personalized medical advice.

## Pull requests

- Keep each pull request focused on one change.
- Test the interface on desktop and mobile widths.
- Describe the user-facing outcome, not only the implementation.
- Do not include copyrighted text copied from a source.
